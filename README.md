
# MealMate

## Catering Resource Planning and Food-Waste Optimization System

MealMate is a rule-based catering management application designed to help catering businesses plan food quantities, estimate ingredient requirements, calculate costs, and monitor food waste.

## Features
- Event and menu management
- Food quantity estimation using guest count and buffer rules
- Ingredient requirement calculation
- Cost estimation and quotation generation
- Food consumption and wastage tracking

## Technology Stack
- Frontend: React
- Backend: Node.js and Express
- Database: SQLite
- ORM: Prisma
